## [0단계] 슬라이드 보여주기 (약 1분)

> "이 슬라이드는 제가 담당한 알고리즘 개발자 역할을 네 가지 영역으로 정리한 것입니다."

**네 가지 영역 짧게 소개:**

1. **학습 알고리즘** – 간격 반복(SRS) 알고리즘, 맞춤형 복습 스케줄
2. **학습 패턴 분석** – 학습 데이터 수집, 성취도 추적, 개인화된 경로
3. **커뮤니티 기능** – 게시판, 댓글, 학습 자료 공유
4. **사용자 소통** – 실시간 피드백, 학습 동기 부여

## [1단계] 기술 스택 & 구현 방식 (약 2분)

> "이제 각 영역을 어떤 기술로 어떻게 만들었는지 말씀드리겠습니다."

### 1) 학습 알고리즘

- **백엔드:** Spring Boot + JPA
- **핵심:** `UserCardProgress` 엔티티에 `nextReview`, `intervalMinutes`, `ease`를 저장해 SM-2 스타일 변형 알고리즘 구현
- **동작:** 사용자가 FAIL/HARD/GOOD/EASY를 누르면 `StudyService`에서 이 값들을 갱신하고, 다음 복습 시각을 계산
- **맞춤형:** 덱별 `learningSteps`(예: 1분→10분), 사용자별 `dailyLimit`, `reviewLimit` 적용

### 2) 학습 패턴 분석

- **데이터:** `study_logs` 테이블에 카드별 평가(FAIL/HARD/GOOD/EASY)와 `studiedAt` 저장
- **통계:** `StatsService`에서 JPQL로 날짜별 집계 → `countByDate`, `countTodayCorrect` 등
- **결과:** Streak, 정답률, 주간 트렌드, 덱별 진행률
- **API:** `/api/stats/dashboard`, `/api/stats/extended`

### 3) 커뮤니티 기능

- **백엔드:** Spring Boot, `PostRepository`에 JPQL `searchWithAuthor` 쿼리
- **공지 상단 고정:** `Sort.by(desc("isNotice"), desc("id"))`로 정렬
- **첨부파일:** `MultipartFile` → UUID로 저장 → `PostAttachment` 엔티티
- **댓글:** `Comment`의 `parent_id`로 대댓글 구조

### 4) 사용자 소통

- **프론트:** React + TypeScript + Axios
- **실시간 피드백:** 학습 시 `/study/review`로 즉시 평가 전송 → `UserCardProgress` 갱신
- **Interval Preview:** `/study/preview`로 버튼 클릭 전 다음 간격 미리보기 (Anki 스타일)
- **동기 부여:** `Streak`, 대시보드 통계, 히트맵(`react-activity-calendar`)

## [3단계] 시연 1 – 학습 모드 (약 1분)

**진행 순서:**

1. **덱 선택 화면** (`/study`)
   - "덱을 선택하면 오늘 복습할 카드와 학습할 새 카드가 로드됩니다."
   - `GET /study/due?deckId=...` 호출

2. **플래시카드 화면**
   - "카드를 클릭하면 뒤집힙니다."
   - "답을 확인한 뒤 FAIL, HARD, GOOD, EASY 중 하나를 선택합니다."
   - "버튼에 보이는 (1분), (1일) 같은 것은 다음 복습 시각입니다. `/study/preview` API로 미리 계산해서 보여줍니다."
   - "버튼을 누르면 `POST /study/review`로 즉시 서버에 전송되고, SRS 알고리즘이 다음 복습 시각을 갱신합니다."

3. **세션 완료 화면**
   - "카드를 다 처리하면 오늘 목표 달성 여부와 함께 더 학습할지, 대시보드로 돌아갈지 선택할 수 있습니다."

## [4단계] 시연 2 – 커뮤니티 게시판 (약 1분)

**진행 순서:**

1. **게시글 목록** (`/posts`)
   - "공지글이 상단에 고정되고, `isNotice` 기준으로 정렬됩니다."
   - "검색, 카테고리 필터, 내가 쓴 글 필터도 지원합니다."

2. **게시글 작성**
   - "제목, 내용, 첨부파일, 카테고리(자유/QnA/스터디)를 입력할 수 있습니다."
   - "작성 후 `FormData`로 `multipart/form-data` 전송해 첨부파일도 함께 저장합니다."
   - "등록 후 바로 해당 글 상세 페이지로 이동합니다."

3. **게시글 상세**
   - "첨부파일은 이미지는 썸네일, 일반 파일은 링크로 표시됩니다."
   - "댓글과 대댓글을 작성할 수 있습니다."
